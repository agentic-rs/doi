# iOS use

Paper Reader is now an Apell applet. Install the local bundle through Apell on the
device. Native iOS builds, signing, secure credentials, and distribution belong
to the Apell host; this repository no longer generates an Xcode project.

Orientation follows the device. PDF page rotation remains available. Native
sharing and browser opening need additional Apell host APIs.

See the [README](../README.md) for build instructions and migration limits.
